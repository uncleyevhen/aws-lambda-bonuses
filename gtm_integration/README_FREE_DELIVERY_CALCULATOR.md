# Калькулятор безкоштовної доставки

## Опис
Скрипт для відображення прогресу до безкоштовної доставки на сторінках інтернет-магазину.

## Особливості
- **Поріг безкоштовної доставки**: 3000 грн
- **Підтримувані мови**: українська та російська
- **Автоматичне визначення мови** на основі `GLOBAL.SYSTEM_LANGUAGE` або URL
- **Responsive дизайн** для мобільних та десктопних версій
- **Реальний час оновлення** при зміні суми замовлення або параметрів доставки

## Підтримувані сторінки
- Сторінка кошика (десктоп і мобільна версії)
- Сторінка оформлення замовлення
- Модальний кошик

## Технічні особливості

### Відстежувані елементи
- `.cart-footer-b` - загальна сума в кошику (десктоп)
- `.cart__total-price` - загальна сума в кошику (мобільний)
- `.order-summary-b` - підсумок замовлення
- `.order-details__total` - деталі замовлення

### Логіка розрахунку
1. Отримує поточну суму замовлення
2. Віднімає вартість доставки (якщо це сторінка checkout)
3. Розраховує залишок до безкоштовної доставки
4. Показує прогрес-бар з відсотком досягнення

### Візуальний компонент
Створює блок `.free-delivery-block` з:
- Логотипом магазину
- Текстом про залишок/досягнення безкоштовної доставки
- Прогрес-баром з анімацією

## API
Скрипт експортує публічний API через `window.FreeDeliveryCalculator`:

```javascript
// Ініціалізація
window.FreeDeliveryCalculator.init();

// Оновлення всіх елементів
window.FreeDeliveryCalculator.updateAll();

// Отримання порогу безкоштовної доставки
window.FreeDeliveryCalculator.getThreshold(); // 3000

// Перевірка стану ініціалізації
window.FreeDeliveryCalculator.isInitialized(); // true/false
```

## Інтеграція з централізованим менеджером
Скрипт інтегрований в `centralized_script_manager.js` з:
- Автоматичним завантаженням на потрібних сторінках
- Правильною ініціалізацією через менеджер
- Логуванням та обробкою помилок

## Налаштування
Основні налаштування знаходяться в об'єкті `CONFIG`:
- `FREE_SHIPPING_THRESHOLD`: поріг безкоштовної доставки
- `CURRENCY`: валюта відображення
- `LOGO_URL`: шлях до логотипу
- `DEBUG`: режим налагодження

## Оптимізація
- Використання debounce для запобігання зайвим викликам
- Intelligent MutationObserver для відстеження змін
- Кешування попередніх значень для уникнення повторних рендерів
- Перевірка наявності елементів перед створенням спостерігачів
