# GTM Integration Scripts

Збірка скриптів для інтеграції з Google Tag Manager та покращення функціональності інтернет-магазину.

## Структура проекту

### Основні файли
- `centralized_script_manager.js` - Централізований менеджер для завантаження та управління скриптами
- `free_delivery_calculator.js` - **НОВИЙ** Калькулятор безкоштовної доставки від 3000 грн
- `bonus_checkoutpage_script.js` - Бонусна система для сторінки checkout
- `bonus_thankspage_script.js` - Бонусна система для thank you сторінки  
- `bonus_text_replacer_script.js` - Заміна тексту "промокод" на "бонуси"
- `online_payment.js` - Обробка онлайн платежів
- `sms_script.js` - SMS функціонал

### Допоміжні файли
- `free_delivery_checker.js` - **ВИХІДНИЙ КОД** Оригінальний скрипт з іншого сайту (для референсу)
- `test_free_delivery_calculator.html` - Тестова сторінка для нового калькулятора

### HTML шаблони
Папка `site_pages/` містить HTML шаблони для різних сторінок:
- `cart.html`, `cart_mobile.html` - Сторінки кошика
- `order_page.html`, `order_page_mobile.html` - Сторінки оформлення замовлення

## Нові можливості

### 🆕 Калькулятор безкоштовної доставки
- **Поріг**: 3000 грн (замість 200 zł)
- **Мови**: Українська та російська (замість польської)
- **Автоматичне визначення мови** на основі `GLOBAL.SYSTEM_LANGUAGE`
- **Responsive дизайн** для всіх пристроїв
- **Інтеграція з централізованим менеджером**

#### Функції калькулятора:
- Відображення прогресу до безкоштовної доставки
- Динамічне оновлення при зміні суми замовлення
- Врахування вартості доставки на checkout сторінках
- Красивий прогрес-бар з анімацією
- Логотип магазину в блоці

## Централізований менеджер скриптів

### Особливості
- **Швидкий режим** - мінімальні затримки завантаження
- **Розумна детекція сторінок** - автоматичне визначення типу сторінки
- **Модульна архітектура** - легке додавання нових скриптів
- **Кешування скриптів** - зменшення навантаження на сервер
- **Логування та діагностика** - детальні логи для налагодження

### Підтримувані типи сторінок
- `checkout-main` - Сторінка оформлення замовлення
- `checkout-complete` - Thank you сторінка
- `cart` - Сторінка кошика
- `cart-modal` - Модальний кошик
- `other` - Інші сторінки

## Конфігурація скриптів

### Активні скрипти
```javascript
// Увімкнені скрипти
'bonus-checkout': {...},           // Бонуси на checkout
'bonus-thankyou': {...},          // Бонуси на thank you
'free-delivery-calculator': {...}, // НОВИЙ калькулятор доставки
'online-payment': {...},          // Онлайн платежі
'text-replacer': {...}            // Заміна тексту (через Cloudflare CDN)

// Відключені скрипти  
'sms-notifications': true,        // Тимчасово відключено
```

### Додавання нового скрипта

1. **Створити файл скрипта** з модульною структурою
2. **Додати конфігурацію** в `SCRIPTS_CONFIG`
3. **Налаштувати логіку завантаження** в `shouldLoadScript()`
4. **Додати спеціальну ініціалізацію** (якщо потрібно) в `loadScript()`

## Тестування

### Тестова сторінка калькулятора
Відкрийте `test_free_delivery_calculator.html` для перевірки:
- Роботи калькулятора на різних елементах
- Зміни мови інтерфейсу  
- Оновлення при зміні цін та параметрів доставки
- Логування та діагностики

### Перевірка в production
```javascript
// Перевірка статусу менеджера
window.ScriptManagerDiagnostics.getHealthStatus();

// Перевірка калькулятора
window.FreeDeliveryCalculator.isInitialized();
window.FreeDeliveryCalculator.getThreshold(); // 3000
```

## Розгортання

1. **Завантажити файли** на сервер в папку з іншими GTM скриптами
2. **Оновити URL** в `SCRIPTS_BASE_URL` конфігурації менеджера
3. **Перевірити роботу** на тестовому середовищі
4. **Активувати в production** через GTM

## Підтримка

- Всі скрипти логують детальну інформацію в консоль (DEBUG_MODE)
- Використовуйте `window.ScriptManagerDiagnostics` для діагностики
- Перевіряйте Network вкладку в DevTools для завантаження скриптів
